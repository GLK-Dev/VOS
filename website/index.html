Six Engines Inside One Single Binary

        
Designed around a strict guardrail: if deterministic SQLite, FTS5, and AST parsing solve it faster and cheaper than AI embeddings, do not add bloat.

      

      

        

          CONTEXT COMPILER
          
Token-Budgeted `vos pack`

          
Solves a deterministic value-per-token knapsack over sessions, Git diff, facts, AST symbol slices, and 1-hop neighbors strictly within your --budget.

          vos pack app "fix auth" --budget 2000 --raw
        

        

          SAFETY SHIELD
          
Blast Simulator & Guardrails

          
Reverse-dependency impact analysis, auto-discovered minimal test commands, and declarative vos.rules.toml architectural boundaries enforced via --strict.

          vos preflight app src/lib.rs && vos guard app --strict
        

        

          COGNITIVE BUS
          
Hash-Anchored Facts & Leases

          
Facts carry SHA-256 content hashes and auto-flip to [Stale] when code changes. Time-bounded area leases and handoffs stop multi-agent edit collisions.

          vos fact add "..." --file src/lib.rs
        

        

          FORENSICS & AST
          
Archaeology & Symbol Slicing

          
Trace Git co-change coupling, doc references, and exact Rust/Python/TS/JS/C/C++ function slices without running a language server daemon.

          vos slice src/search.rs --symbol rank_hits
        

        

          RECOVERY ENGINE
          
Self-Calibrating Telemetry

          
Computes empirical false-alarm and missed-difficulty rates across your completed work_sessions to tune recovery scoring automatically.

          vos continue app && vos calibrate
        

        

          VISUALIZATION
          
On-Demand Constellation HUD

          
Run `vos ui` for a zero-dependency local SVG portfolio map with drill-down from workspace to AST symbol, or `vos ui --once` right in the terminal.

          vos ui --port 4173
